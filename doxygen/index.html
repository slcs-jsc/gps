GPS Code Collection

The GPS Code Collection provides C-based tools and library routines for the analysis of GPS radio occultation observations.

Introduction

This Doxygen manual focuses on the source-level reference for the project:

  • core data structures declared in libgps.h
  • helper routines implemented in libgps.c
  • command-line tools in src/
  • relationships between functions, files, and call sites

The source code of the GPS Code Collection is available from the git repository. Please see the README.md for installation notes and repository-level guidance. A lighter user-facing manual is available at https://slcs-jsc.github.io/gps.

Structure

The main source tree is organized as follows:

  • libgps.h and libgps.c: shared data structures, netCDF helpers, interpolation utilities, and analysis routines
  • *.c in src/: command-line executables for time conversion, profile extraction, perturbation analysis, tropopause diagnostics, and related tasks
  • jurassic.c and jurassic.h: vendored source from the external JURASSIC radiative transfer model

The Doxygen reference is centered on the GPS Code Collection code. Vendored JURASSIC sources are kept in this repository for convenience but are documented in their own upstream project.

Build

Typical build and test workflow:

cd src
make
make check

If local copies of GSL and netCDF are needed, build them first:

cd libs
./build.sh
